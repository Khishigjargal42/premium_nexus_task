# Өгөгдлийн шинжээчийн даалгавар

## 1. Төслийн зорилго

Энэхүү даалгаврын хүрээнд борлуулалт, хэрэглэгч, бүтээгдэхүүн, салбар, inventory болон хэрэглэгчийн санал хүсэлтийн өгөгдөлд шинжилгээ хийж, бизнесийн гол insight болон хэрэгжүүлэх боломжтой санал зөвлөмжүүдийг тодорхойлсон.

Шинжилгээний үндсэн зорилго:

- Өгөгдлийн чанарыг шалгах, шаардлагатай цэвэрлэгээ хийх
- Борлуулалтын гүйцэтгэл болон өөрчлөлтийг шинжлэх
- Хэрэглэгчийн худалдан авалтын зан төлөвийг ойлгох
- Бүтээгдэхүүн болон ангиллын гүйцэтгэлийг харьцуулах
- Inventory-ийн эрсдэлийг тодорхойлох
- Хэрэглэгчийн санал хүсэлтээс бүтээгдэхүүн сайжруулах боломж олох
- Шинжилгээний үр дүнг бизнесийн санал зөвлөмж болгон боловсруулах

# 12. Нэмэлт асуулт — Monty Hall Problem

## Хариулт

**Би сонголтоо солино.**

Эхэндээ гурван хаалга байхад аль нэгийг нь сонгоход машин таарах магадлал 1/3 байна. Тэгэхээр миний сонгосон хаалга буруу байх магадлал 2/3 гэсэн үг.

Хөтлөгч машины хаана байгааг мэддэг бөгөөд үлдсэн хоёр хаалганаас заавал хоосон хаалгыг нээж өгч байгаа. Тиймээс тэр хаалга нээгдсэнээр миний эхний сонголт гэнэт зөв болохгүй.

Хэрэв би анхнаасаа буруу хаалга сонгосон бол үлдсэн, хөтлөгчийн нээгээгүй хаалга машинтай байх болно. Анх буруу сонгох магадлал 2/3 учраас сонголтоо солиход машин авах магадлал 2/3 болно.

Тиймээс:

- **Сонголтоо солихгүй бол:** 1/3 буюу 33.3%
- **Сонголтоо сольбол:** 2/3 буюу 66.7%

Иймээс би **сонголтоо солихыг сонгоно**. Гол шалтгаан нь хоёр хаалга үлдсэндээ биш, харин хөтлөгч машины байршлыг мэдэж, зориуд хоосон хаалгыг нээж байгаа явдал юм.
